Why Continuity

A new session should not mean starting over.

Every coding agent brings its own tools. Continuity gives them a shared, project-bound record of what has been learned and what needs to happen next.

◎

Project identity

One local identity follows a project across agents, sessions, and Git worktrees.

✳

Durable memory

Keep source-backed facts and attributed lessons with their trust level and history.

↗

Clear handoffs

Pass on the goal, completed work, remaining steps, decisions, and risks.

⌁

Visible provenance

See which current sources support context, and why an item was selected.

Built for real projects

Context with boundaries.

Local by default

No hosted account or model key is required for the default experience. Git and your files remain authoritative.

Scoped to the project

The trusted host fixes project scope. Context from another project cannot be retrieved implicitly.

Evidence stays attached

Memory keeps provenance and revision history. Conflicting claims are quarantined for review.
